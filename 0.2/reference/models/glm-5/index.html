    glm-5¶

    zai-org/GLM-5-FP8, architecture GlmMoeDsaForCausalLM: 78 layers, weights in fp8 (bf16 for some nodes). The graph below is derived from the model's config.json at revision 4f96cc5eec29; Model graphs explains how to read it, and the glossary defines its terms.

    Layer stack¶

    The stack is a prologue of attn_dense ×3; then the pattern (attn_moe) repeated 75 times.

    Sequence mixing lists every attention and recurrent kind in the stack, including the small gqa attention an indexer uses to choose which tokens a sparse layer reads.

    Dimensions¶

    Quantity Value
    Hidden size 6 144
    Vocabulary 154 880
    Tied embeddings no
    Weights fp8 (bf16 for some nodes)
    Sequence mixing gqa + sparse_mla
    Routed experts 256, top-8
    Speculator deepseek_mtp, 1 token

    Layer kinds¶

    Each layer kind is a small graph of primitives. Nodes are listed in the order graph.yaml gives them; the edges between them are in the file. Runs when is a collective's emit condition, which depends on the deployment's parallelism; a blank means the node always runs. Parameters are the dimensions the primitive is priced from, named as in graph.yaml.

    Head¶

    Runs once per forward pass, after the last layer.

    # Op Role Runs when Parameters
    0 Elementwise final_norm
    1 GEMM lm_head n=154880, k=6144

    Speculator¶

    Method deepseek_mtp, proposing 1 draft token per step. Its stack is the pattern (attn_moe) once.
