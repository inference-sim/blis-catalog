    llama-2-7b-hf¶

    meta-llama/Llama-2-7b-hf, architecture LlamaForCausalLM: 32 layers, weights in fp16. The graph below is derived from the model's config.json at revision 01c7f73d771d; Model graphs explains how to read it, and the glossary defines its terms.

    Layer stack¶

    The stack is the pattern (dense) repeated 32 times.

    Layer kinds¶

    Each layer kind is a small graph of primitives. Nodes are listed in the order graph.yaml gives them; the edges between them are in the file. Runs when is a collective's emit condition, which depends on the deployment's parallelism; a blank means the node always runs. Parameters are the dimensions the primitive is priced from, named as in graph.yaml.

    dense¶

    32 layers.

    # Op Role Runs when Parameters
    0 Elementwise input_norm
    1 GEMM qkv_proj n=12288, k=4096
    2 Attention kind=gqa, n_q=32, n_kv=32, d_h=128
    3 GEMM o_proj n=4096, k=4096
    4 AllReduce attn_out tensor_parallel
    5 Elementwise post_attn_norm
    6 GEMM mlp_gate_up n=22016, k=4096
    7 GEMM mlp_down n=4096, k=11008
    8 AllReduce mlp_out tensor_parallel_unless_sp_moe

    Head¶

    Runs once per forward pass, after the last layer.

    # Op Role Runs when Parameters
    0 Elementwise final_norm
    1 GEMM lm_head n=32000, k=4096
