    Layer kinds¶

    Each layer kind is a small graph of primitives. Nodes are listed in the order graph.yaml gives them; the edges between them are in the file. Runs when is a collective's emit condition, which depends on the deployment's parallelism; a blank means the node always runs. Parameters are the dimensions the primitive is priced from, named as in graph.yaml.

    dense¶

    80 layers.

    # Op Role Runs when Parameters
    0 Elementwise input_norm
    1 GEMM qkv_proj n=10240, k=8192
    2 Attention kind=gqa, n_q=64, n_kv=8, d_h=128
    3 GEMM o_proj n=8192, k=8192
    4 AllReduce attn_out tensor_parallel
    5 Elementwise post_attn_norm
    6 GEMM mlp_gate_up n=57344, k=8192
    7 GEMM mlp_down n=8192, k=28672
    8 AllReduce mlp_out tensor_parallel_unless_sp_moe
