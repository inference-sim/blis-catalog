    nemotron-3-ultra-550b-a55b-nvfp4¶

    nvidia/NVIDIA-Nemotron-3-Ultra-550B-A55B-NVFP4, architecture NemotronHForCausalLM: 108 layers, weights in bf16 (fp8, nvfp4 for some nodes). The graph below is derived from the model's config.json at revision 02462641f13d; Model graphs explains how to read it, and the glossary defines its terms.

    Layer stack¶

    The stack is the pattern (mamba, moe, mamba, moe, mamba, moe, mamba, attention, moe, mamba, moe, mamba, moe, mamba, attention, moe, mamba, moe, mamba, moe, mamba, moe, mamba, attention, moe) repeated 4 times; then an epilogue of mamba, moe, mamba, moe, mamba, moe, mamba, moe.

    Dimensions¶

    Quantity Value
    Hidden size 8 192
    Vocabulary 131 072
    Tied embeddings no
    Weights bf16 (fp8, nvfp4 for some nodes)
    Sequence mixing gqa + mamba2
    Routed experts 512, top-22
    Speculator nemotron_h_mtp, 1 token

    Layer kinds¶

    Each layer kind is a small graph of primitives. Nodes are listed in the order graph.yaml gives them; the edges between them are in the file. Runs when is a collective's emit condition, which depends on the deployment's parallelism; a blank means the node always runs. Parameters are the dimensions the primitive is priced from, named as in graph.yaml.

    48 layers.

    # Op Role Runs when Parameters

    1 RecurrentUpdate recurrent_kind=mamba2, n_heads=256, state_size=128, n_groups=8, conv_kernel=4, intermediate_size=16384, state_dtype=fp32
    2 GEMM mixer_out n=8192, k=16384, weight_dtype=fp8
    3 AllReduce mixer_out tensor_parallel

    Head¶

    Runs once per forward pass, after the last layer.

    # Op Role Runs when Parameters
    0 Elementwise final_norm
    1 GEMM lm_head n=131072, k=8192

    Speculator¶

    Method nemotron_h_mtp, proposing 1 draft token per step. Its stack is the pattern (attention, moe) once.
